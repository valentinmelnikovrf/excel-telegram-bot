Excel Помощник – это Telegram бот, который помогает обычным людям работать с Excel таблицами без знания сложных формул. Просто загрузите файлы, и бот сделает всё сам!

✨ Возможности
🔗 Объединение таблиц (ВПР)
Соединяет два Excel файла в один по общему ключу

Автоматически находит и добавляет недостающие данные

Подробная статистика до и после объединения

Проверка файлов перед оплатой

📊 Сводные таблицы (скоро)
Группировка данных по категориям

Подсчет сумм, средних значений и количества

Удобные отчеты одним кликом

📋 Другие инструменты (в разработке)
Очистка данных от дубликатов

Разделение таблиц по условиям

Объединение нескольких файлов

🎯 Для кого этот бот
Продавцы – добавить категории к товарам

Менеджеры – объединить списки клиентов

Бухгалтеры – соединить таблицы с ценами

Все, кто работает с Excel – без знания формул и ВПР!

🚀 Как начать пользоваться
Перейдите в бота: @excel_vm_bot

Нажмите /start

Выберите "Объединить таблицы"

Загрузите первый файл (главный)

Загрузите второй файл (источник)

Проверьте статистику и оплатите

Получите готовый результат!

📸 Пример работы
Шаг	Что видит пользователь
1	Загружает список товаров
2	Загружает список категорий
3	Получает объединенный файл
Было:

text
Файл 1: Товары (Код, Название, Цена)
Файл 2: Категории (Код, Категория)
Стало:

text
Результат: Товары (Код, Название, Цена, Категория)
💰 Монетизация
Объединение таблиц – 10⭐ за операцию

Сводные таблицы – 15⭐ (скоро)

Оплата только после успешной проверки!

Админ может менять цены через админ-панель

🛠 Технические требования к файлам
✅ Формат: только .xlsx (Excel 2007 и новее)

✅ Размер: до 20 МБ

✅ Обязательный столбец: "Ключ" в обоих файлах

✅ Без паролей и защиты

🔧 Для администраторов
В боте есть удобная админ-панель:

Изменение цен на услуги

Просмотр статистики использования

Управление настройками

Команды:

/admin – открыть админ-панель

Установка цен через кнопки

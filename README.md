Excel Секретарь – это Telegram бот, который помогает обычным людям работать с Excel таблицами без знания сложных формул. Просто загрузите файлы, и бот сделает всё сам!

✨ Возможности
**🔗 Объединение таблиц (ВПР)**
Соединяет два Excel файла в один по общему ключу
Автоматически находит и добавляет недостающие данные
Подробная статистика до и после объединения
Проверка файлов перед оплатой

**📊 Создать сводную таблицу (НОВИНКА!)**
Группировка данных по категориям (до 5 столбцов)
Выбор числовых столбцов для расчетов
Три типа расчетов: Сумма, Количество, Среднее

Умная обработка пустых значений (заменить на 0 или пропустить)
Наглядный пошаговый интерфейс с визуальным отображением выбора
Итоговая строка с общими значениями

**📋 Другие инструменты (в разработке)**
Очистка данных от дубликатов
Разделение таблиц по условиям
Объединение нескольких файлов

**🎯Для кого этот бот**
Продавцы – добавить категории к товарам
Менеджеры – объединить списки клиентов
Бухгалтеры – соединить таблицы с ценами
Аналитики – быстро создать сводные отчеты
Все, кто работает с Excel – без знания формул и ВПР!

**🚀 Как начать пользоваться**
Перейдите в бота: @excel_vm_bot
Нажмите /start
Выберите нужный инструмент:

🔗 Объединить таблицы (ВПР) – для соединения двух файлов
📊 Создать сводную таблицу – для анализа данных
Следуйте пошаговым инструкциям с картинками
Оплатите (только после успешной проверки)
Получите готовый результат!

**📸 Пример работы со сводной таблицей**
Шаг	Что видит пользователь
1	Загружает файл с продажами (магазины, товары, суммы)
2	Выбирает столбцы для группировки: 📌 Магазин, 📌 Дата
3	Выбирает столбцы для расчетов: 📌 Продажи, 📌 Количество
4	Выбирает типы расчетов: 📌 Сумма, 📌 Среднее
5	Настраивает обработку пустых значений
6	Получает готовую сводную таблицу

🛠 Технические требования к файлам
Для ВПР (объединение):
✅ Формат: только .xlsx (Excel 2007 и новее)
✅ Размер: до 20 МБ
✅ Обязательный столбец: "Ключ" в обоих файлах
✅ Без паролей и защиты

Для сводных таблиц:
✅ Формат: .xlsx
✅ Размер: до 20 МБ
✅ Наличие числовых столбцов для расчетов
✅ Наличие категориальных столбцов для группировки

🔧 Для администраторов
В боте есть удобная админ-панель:
Изменение цен на услуги
Просмотр статистики использования
Управление настройками

Команды:

/admin – открыть админ-панель
Установка цен через кнопки
